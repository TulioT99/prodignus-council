# Publication Templates

Reusable publication workflows for Prodignus Council / PKOS governance.

**Governing standard:** [OPS-0002 — Canonical Implementation Baseline Publication Standard](../OPS-0002-canonical-implementation-baseline-publication.md)  
**Automated gate:** [OPS-0003 — Publication Integrity Validator](../OPS-0003-publication-integrity-validator.md)

| Template                                                                                               | Use for                                          |
| ------------------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| [CANONICAL_IMPLEMENTATION_BASELINE_PUBLICATION.md](./CANONICAL_IMPLEMENTATION_BASELINE_PUBLICATION.md) | Master publication workflow (normative)          |
| [WP_PUBLICATION.md](./WP_PUBLICATION.md)                                                               | Work Package (WP) publications                   |
| [ENG_PUBLICATION.md](./ENG_PUBLICATION.md)                                                             | Engineering Specification (ENG) publications     |
| [ARR_PUBLICATION.md](./ARR_PUBLICATION.md)                                                             | Architecture Readiness Review (ARR) publications |
| [OPS_PUBLICATION.md](./OPS_PUBLICATION.md)                                                             | Operations (OPS) publications                    |

All templates **must** include the Baseline Integrity Check defined in OPS-0002 and run the OPS-0003 validator before publication proceeds.
